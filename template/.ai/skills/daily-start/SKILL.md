# 開工

**目標：在 5 分鐘內讓使用者清楚今天自己只要專注哪 3 件事與各自的第一步；能由 AI 代勞的查證與草稿直接做完，不把壓力留給使用者。**

## 步驟

1. **讀早報**：新對話開始時 `session_brief.py` 會注入今日早報；若沒看到，執行 `python .ai/hooks/session_brief.py --selftest` 取得最新狀態（含最近跨 AI 交接、昨日收工「明天第一件」、今日任務與逾期）。
2. **掃描待辦與外部來源**：
   - 執行 `python .ai/scripts/tasks.py list` 檢視所有未結任務卡與逾期項目。
   - 若目前對話有接上信箱或行事曆工具，檢查近 24 小時未回信與未來 14 天重要截止，有需要追蹤的用 `python .ai/scripts/tasks.py new "<標題>" ...` 建成任務卡。
   - 若需要寄信、傳訊息或花錢授權，只備草稿不送出。
3. **鎖定今天最多 3 件**：
   - 把今天本人要動手的任務卡設為 `status: 今天`（硬上限 3 張，多餘的改為 `本週`；AI 可自行背景執行的不計入 3 張上限）。
   - 每張「今天」卡的 `next` 欄位必須是一個 **2 分鐘內能開始的具體第一步**。
   - 若今天有多個高優先待辦需取捨，依 `.ai/skills/decision-options/SKILL.md` 用推薦排序選項請使用者拍板。
4. **存開工快照與流水帳**：
   - 執行 `python .ai/scripts/tasks.py snapshot --kind am`。
   - 在 `log.md` 末尾補一行：`- YYYY-MM-DD 開工：本人 N 件、AI 派出 M 件`。
5. **開始處理**：先替使用者把 AI 可直接做完的事做掉，回報時把「今天 3 件與第一步」放在最前面。

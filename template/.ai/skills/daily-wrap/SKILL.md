# 收工

**目標：讓使用者放心關機。今天做完什麼有證據、沒做完的全落進任務卡、明天早上一打開就看得到第一步。**

## 步驟

1. **產生結算草稿與唯一正本檢查**：
   - 執行 `python .ai/scripts/tasks.py wrap-draft` 產出 `.ai/logs/daily/YYYY-MM-DD.md` 草稿（自動計算完成度與未完成清單）。
   - 執行 `python .ai/scripts/tasks.py stray`，若發現任務卡以外的 `- [ ]` 第二來源待辦，轉成任務卡或改為連結，維持唯一正本。
2. **「今天」卡歸零（不可殘留）**：
   - 所有尚未完成且 `status` 仍是 `今天` 的卡片，依情況改為 `明天`、`本週`、`等別人` 或 `之後`，並更新 `next` 下一步。
   - 不再做的任務改為 `status: 取消`（不刪檔）。
3. **提煉經驗與減法（至多 3 條）**：
   - 回顧今天哪裡卡關、重工或被使用者糾正，寫成「事件、根因、改進位置」（至多 3 條），並順手把過時重複的說明刪掉。
4. **填完日報與即時交接**：
   - 補齊 `.ai/logs/daily/YYYY-MM-DD.md` 內的「明天第一件（本人與 AI 各一件）」，明天開工 `session_brief.py` 會自動讀它。
   - 在 `log.md` 末尾加一行：`- YYYY-MM-DD 收工：完成 X/Y、明天第一件 <標題>`。
   - 執行 `python .ai/hooks/live_handoff.py log ...` 記錄收工交接。
5. **儲存晚間快照**：執行 `python .ai/scripts/tasks.py snapshot --kind pm`（可選）。

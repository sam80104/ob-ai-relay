# 共用工作準則（Claude Code、Codex、Antigravity 唯一正本）

所有進駐本 Vault 的 AI 工具一律遵守本檔案規範，不另起爐灶。

## 1. 語言與表達
- 一律使用**台灣繁體中文**回覆（專有名詞可附英文對照），結尾簡述誰做了什麼。
- 回覆先給結論，多件事使用表格（事項｜結論｜我做了什麼｜你要做什麼）或條列呈現。
- 禁用破折號與波浪號區間，區間改寫為「到」。

## 2. 任務唯一正本原則
- **待辦唯一正本**是 `任務系統/專案/*/任務卡/*.md` 的 frontmatter `status`（入口看板：`任務系統/任務看板.base`）。
- 不在專案 README 或一般筆記裡放可勾選的 `- [ ]` 待辦（避免第二來源不同步）；頁面只放卡片連結或內嵌 `![[任務看板.base#本案]]`。
- 不做的任務不刪檔，改為 `status: 取消`（或執行 `python .ai/scripts/tasks.py card "<關鍵字>" --status 取消`）。
- 檢查有沒有任務卡以外的第二來源待辦：跑 `python .ai/scripts/tasks.py stray`。

## 3. 做事與生成選項規範（三家 AI 強制落實）
- **能做的直接做到底**：可回復的本機查證、建檔、改稿與驗證直接做完，不要反覆問「要不要我做」。
- **不確定或要拍板一律給規範選項**：凡遇紅線、缺關鍵資訊或需使用者做決策時，三家 AI（Claude 用 `AskUserQuestion`、Antigravity 用 `ask_question`、Codex 用結構化推薦選項）**必須先寫完整前因後果**（哪件事、目前現況、為什麼要選），**再給依推薦順序排列的選項**（首項標推薦，並寫出每個選項的原因與代價），不在純文字裡丟開放式問題要使用者盲選。詳細標準見 `.ai/skills/decision-options/SKILL.md`。

## 4. 開工、收工與跨 AI 無縫接力
- **開工**：使用者說「開工」時，照 `.ai/skills/daily-start/SKILL.md` 執行（讀早報、鎖定今天最多 3 件與第一步、存開工快照、記 `log.md`）。
- **收工**：使用者說「收工」或「今天到這」時，照 `.ai/skills/daily-wrap/SKILL.md` 執行（跑 `wrap-draft`、歸零「今天」卡、提煉最多 3 條經驗、寫下「明天第一件」與 `log.md`）。
- **即時交接**：只要本輪修改了 Vault 檔案，結束前執行以下指令寫入三行接力棒，讓下一家 AI 開新對話說「繼續」即可無縫接手：
  ```bash
  python .ai/hooks/live_handoff.py log --tool "<工具名>" --title "<主題>" --done "<做了什麼>" --result "<結果路徑>" --next "<下一步>"
  ```

## 5. 安全紅線
- 未經使用者當次明確同意，**絕不**對外寄信、傳訊息、公開發布或執行付款／授權操作。
- 永久刪除重要資料前必須先經使用者確認。

# 行動入口

所有專案與待辦的唯一入口是 [[任務系統/任務看板.base|任務看板]]（包含專案卡、我要做、依專案、依階段、逾期要追、四象限視圖）。

## 日常四句口令（對任一家 AI 直接說）

- **「開工」**：讀早報與昨天未完成，鎖定今天最多 3 件任務與第一步。
- **「繼續」**：讀取最近兩筆跨 AI 交接，無縫接續上一家 AI 的進度。
- **「收工」**：結算今天完成度、歸零「今天」卡並產出日報與明天第一件。
- **「把 XX 完成／取消」**：直接更新任務卡 `status`。

## 常用本機指令速查

```bash
python .ai/scripts/tasks.py list            # 列出未結任務卡
python .ai/scripts/tasks.py stray           # 檢查有沒有第二來源待辦
python .ai/scripts/tasks.py snapshot --kind am   # 存開工快照
python .ai/scripts/tasks.py wrap-draft      # 產出今日收工草稿
```
